# JOB LETTER TEMPLATE

One letter per job. Everything in the letter. Then silence until a file
lands. Copy this shape for every job — a part left empty means the letter
is not ready. (Adapted from the original operation's template; see
SUPERVISION_LOOP.md for how the seats work.)

## 1. THE JOB
- What to build / do, in one plain sentence:
- Source (exact file or link):
- Working folder:
- Rules and skills that govern this job (names only — already installed):

## 2. DONE MEANS
- Finished file lands at: <exact path + name>
- Its checker passes and writes its report at: <exact path>
- A DONE note (small text file, same folder) with: file name, size, MD5,
  checker verdict in one line.

## 3. STOP RULE (hard)
- The same step fails 2 times → STOP. Do not try a third way.
- Write the STUCK file (part 4) and wait. No workarounds around the stop rule.

## 4. CHECK-IN RULE (files only — no chat reports)
- Progress and questions travel as FILES, never as chat claims.
- STUCK file (same folder, name STUCK_<job>.txt) with exactly:
  - status: stuck
  - step: which step failed
  - tried: what was tried (the 2 attempts, one line each)
  - need: the one thing the supervisor must decide or supply

## 5. THE LINE + THE BUDGET
- Never: post anything (unless the owner made posting your job); change
  branding or rule files; delete finished files; touch another seat's work.
- Budget: max 2 attempts per step; if the job cannot finish inside this
  letter, STUCK file — never a bigger invention.
- Known cases: <case → action list, filled per job>

## 6. THE SUPERVISOR'S GATE
- The CHECKER does the FULL check (frames, captions, sync, loudness,
  sentence ends) and writes a REPORT FILE with numbers next to the DONE
  note. A delivery without that report is not done.
- The supervisor then checks SMART SPOTS only: file size + MD5, frame 0,
  one contact sheet of ~20 frames, caption case at random spots, sound fit
  at one random moment, the report's numbers.
- Any spot fails → the supervisor does the FULL check for that clip.
- First clip of any NEW STYLE → full check, always.
- A fault that ever slips through to the owner → that fault type joins the
  checker list forever + the next 3 clips get the full check.
- The owner is the final eye on every clip. This gate never replaces him.

## 7. CLOSE OF JOB (fresh session per job)
- This job runs in a FRESH session. Before it closes, write every new
  lesson from this job as ONE short line into the state note named in this
  letter — lessons live in files, never only in the chat.
- The next job's fresh session starts by reading: its job letter + the
  state note. Nothing else is carried over.

## ADVANCE QUEUE (optional)
- A letter may carry Job A + Job B. When A is done, start B at once —
  do not wait for the supervisor's next visit.
