# WHAT YOU STILL NEED (not in this pack, and why)

This pack is the recipe and the skills. These pieces are deliberately NOT in
it. Each one comes from the owner or from a separate step.

1. **The Debate Clipper project code.**
   It lives on the original owner's pc and is not in this zip. Two clean ways
   to get it:
   - A PRIVATE GitHub repository: the original owner pushes the code there and
     invites the receiving owner as a collaborator. Never a public repo.
   - A zip of the project folder, made on the pc, sent owner to owner.
   Either way: videos, rendered clips, job outputs, caches, and backup folders
   should be excluded — code only. The code must be secret-scanned before it
   is sent anywhere (see INSTALL_AND_SETUP.md, part A).

2. **Your own YouTube/browser cookies** — for downloads that hit bot gates.
   The receiving owner exports his own from his own signed-in browser, on his
   own machine. Never ask for, accept, or use the original owner's cookies.

3. **Your own accounts and branding.**
   Your TikTok/social accounts, your own logo files, name, and handle per
   account. Store them per account — accounts do not share one brand.

4. **Music beds.**
   The standing bed, "Crypto" by Kevin MacLeod (CC BY 4.0), IS included in
   the project (assets/music/) with its credit line — use it and keep the
   credit in your descriptions. Any other bed: use tracks you have the right
   to use, and understand the risk before using any commercial track
   (possible mute/claim on TikTok). The rules fix the loudness (−19.5 LUFS)
   and that the bed must sync with the picture.

5. **The Whisper model file.**
   The speaker/diarization and face models ARE included in the project
   (assets/models/). The one file that is NOT is the 145 MB Whisper base
   model — it is over GitHub's 100 MB single-file limit. faster-whisper
   downloads it automatically from Hugging Face on first use; let it, once,
   with a good connection.

6. **The hit-mining data.**
   The original operation keeps a data file on the top niche clipper's
   videos. That data file is not shared — use the research-tools skill to
   build your own map (see FRIEND_CLIPPER_RULES.md section 1).

Note on branding inside the project: the project contains the ORIGINAL
owner's account configs and one of his logos. Those are his brands — do not
post with them. Replace them with your owner's own (point 3).

7. **Your own machine setup.**
   A Windows PC with the environment in INSTALL_AND_SETUP.md, enough disk for
   source videos, and your own Muse signed in as you.

## What will NOT be shared, ever

Passwords, sign-in words, cookies, API keys, or access to the original
owner's accounts and machines are not part of this share — for either side's
safety. If a step seems to need one of those, it is your own version of that
thing that is needed.
